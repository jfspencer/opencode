# The tree-sitter grammars opencode-tui-markup compiles, at the versions of the WASM grammars OpenTUI 0.8.1 bundles (javascript,
# typescript, typescriptreact, markdown, markdown_inline, zig) and the TUI downloads (packages/tui/src/parsers-config.ts).
# Each WASM was checked against its parser.c (ABI, symbol, state and field counts) and against the source
# archive its release publishes: the archive is used where its parser.c differs from the tag's (rust: version
# metadata only; scala: regenerated at ABI 15 by tree-sitter 0.25.6, as its WASM was). Swift's tag has no
# generated sources, so its release archive is used. port/scripts/vendor-grammars.sh fetches the sources listed
# here into port/.vendor/tree-sitter (checking each archive sha256), where build.rs compiles them.
#
