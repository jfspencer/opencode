segfault when calling free() twice?

Hi all, my program crashes with Segmentation fault (core dumped). Here's the code:

#include <stdlib.h>
int main(void) {
    char *p = malloc(16);
    free(p);
    free(p);   /* <-- crash here */
    return 0;
}

Why???

newbie_coder wrote:

Why???

Because freeing the same pointer twice is undefined behaviour. Set it to NULL after freeing:

free(p);
p = NULL;
free(p); /* free(NULL) is a no-op */

Also, run it under Valgrind:

$ valgrind ./a.out
==1234== Invalid free() / delete / delete[] / realloc()
==1234==    at 0x483CA3F: free (vg_replace_malloc.c:540)

Technically it's "undefined behavior" in the standard (§7.22.3.3 ¶2), but yes.

Spoiler: what the standard actually says

if the argument does not match a pointer earlier returned by a memory management function, or if the space has been deallocated by a call to free or realloc, the behavior is undefined.
